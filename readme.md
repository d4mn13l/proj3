# proj3

a "tech"-demo for a "horror" "game".

an extension of a wolfenstein-like 3d raycasting renderer we did at university which i wanted to extend to a short horror game.
i have finished most of the technical stuff but rn i dont have the time or motivation to do the actual game part, maybe i will one day or not.
what exists so far is what was supposed to be the intro to the game.
it is playable but there is not a lot to play.


## running
this thing is written for the nintendo 3ds, but you can use an emulator like azahar to run it on another system.
it is probably not that difficult to port it to smth like sdl but as i said i have neither motivation nor time rn. 

## controls
- d-pad / joystick: move
- l / r: turn
- y: interact with stuff
- x: cycle items
- a: use items
- b: skip text
- start: exit

## notes about the controls
- items arent really used at all its more just the system exists.
- things you can interact with are always sprites, so not walls. when you are in range it will also say that you can interact with it on the bottom screen.


## gameplay

as i said there is not really a lot of gameplay so i though id just kinda put what i had in mind here:
i wanted to make this one of those games where you have to collect all things of some kind while being chased by some monster (very original ik).
if you are close to it the lights start to blink and the closer you get the longer they stay black.
i have no idea if that actually works as a main gameplay idea but i thought it was maybe interesting enough to try out.
